# 料段账房数据字典

## 来源文件

| 字段 | 定义 |
|---|---|
| 锯切计划 | 文本主键，保留前导零。跨业务键不汇并记录。 |
| 修订号 | 正整数。最高版优先；最高同版字段冲突或存在同版、更新版的未采信记录时隔离，旧版无法接替。 |
| 提交时间 | ISO 8601，必须带 UTC 偏移量。标准化后展示 UTC。 |
| 原始备注 | 可空，允许引号内换行。 |
| 标准棒料毫米、锯缝毫米、回用下限毫米、余料清单、切件规格 | 必填字段。多项字段用半角分号隔开，显式空集合用 `无`。 |

识别 `UTF-8`、UTF-8 BOM 与独立的 `GB18030` 文件。`业务编号`、`版本`、`更新时刻`、`备注` 为旧版表头别名。新旧名同时出现会被拒绝。`-`、`N/A`、`NULL`、`未知` 和空串均按必填值缺失处理。物理行号指 CSV 逻辑记录起始行。

## 计算字段

切件和余料都以 `长度毫米x件数` 记录，可用 `无` 表示无余料。切件降序，当前最短可容纳料段先用。

用掉整段时锯缝为零。新料、回用料、切件和损耗按毫米守恒；对账值为领用新棒总长。

数值在服务端以十进制定点方式计算，对外按字符串传输。单文件上限 128 KiB，复合字段最多 240 个项目，个别字段还有业务上限。格式无法恢复的 CSV 整批拒绝，列数、缺字段、来源冲突和业务条件错误逐条隔离。

## 复算与外部清单

外部清单包含 `锯切计划` 和 `外部记录值(毫米)`，允许省略不在对账范围内的键。同一键重复会拒绝该清单。结果数值单位为 **毫米**。差值按本次复算减外部记录，缺一侧时差值计算以 0 占位并保留缺失原因。

同一对输入字节与规则版本生成同一批次，导出包含两个文件摘要、证据行、单边差异和复核修订记录。复核保存前检查当前版本，在有隔离、差异或退回时必须填写意见。

## 迟到补正与签核失效

补正文件走与来源相同的解析、归一、版本与排料流程。只有存在复核记录的已签批次会被评估，未签批次不受影响。逐业务键判定：

- 补正的业务字段（五个必填字段）与原签核生效记录完全一致时为 `kept`，仍按原签核发料。
- 字段实际变化且修订号更高时为 `invalidated`：该键的旧签核结论失效，按补正后的记录重算料段去向与新棒用量；同批未改到的业务键仍按原签核发料。
- 同版字段冲突（`REV_CONFLICT`）、较新来源未采信（`REV_BLOCKED`）或重算触发业务错误时只标 `pending` 待人工核可，绝不覆盖原结论。
- 旧签核原文（来源行、原用量、料段依据、复核时间线）保持不变并可通过批次详情与证据导出查询；补正结果挂在批次详情的 `corrections` 与导出的同名键下。

补正以来源字节摘要去重：同一补正重复提交或并发重跑只生成一条补正登记和一组失效记录。接口见 `POST /api/corrections`、`GET /api/corrections`、`GET /api/corrections/{id}`。
